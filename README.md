## 這是什麼

啟示錄全書二十二章的完整研經材料，做成一個可以離線使用的網頁 App。

一節一節從希臘文原文讀起，附上字義、文法、句法的說明，再帶到神學重點、基督中心的讀法，最後是可以直接上台的講章逐字稿與生命應用。

三種語言，同一份內容，在 App 裡隨時切換。

| | 繁體中文 | 简体中文 | English |
|---|---|---|---|
| 檔案 | `index.html` | `sc.html` | `en.html` |
| 聖經版本 | 和合本 | 和合本 | World English Bible |

## 內容規模

```
經文        405 節（二十二章，全書）
解經段      219 段（逐節覆蓋，無遺漏）
講章        22 篇逐字稿
```

每一個解經段都包含六層：

| 層 | 內容 |
|---|---|
| **和合本經文** | 該段的經文 |
| **希臘原文** | Nestle 1904 公有領域校勘本 |
| **直譯** | 盡量貼著原文語序，看見中譯背後的結構 |
| **關鍵字** | 原文｜音譯｜Strong's｜字根｜基本字義｜本節語境 |
| **文法解析** | 時態、語態、語氣、格位，並說明「這對理解本節有什麼影響」 |
| **經文解釋** | 整合字義、文法、上下文與背景，並區分「經文明說的」與「可合理推論的」 |

## 解經上的幾個堅持

**分清楚哪些是經文說的，哪些是推論。** 每一段解經的結尾都會分開寫「經文本身明確表達的」與「可以合理推論的」。

**有爭議的地方並陳，不說死。** 千禧年的三種立場、兩個見證人的四種讀法、巴比倫指什麼、13:8 的文法歧義——都把主要立場與各自的經文根據列出來，說明哪一種內證較強，但不宣稱唯一答案。全書共 80 處這類並陳。

**明確標出不可以那樣講的地方。** 全書 45 處紅標，例如：

- 獸的印記不可指認為某項技術——經文說得清楚，受印記的人是在**敬拜**獸像，那是敬拜的行為
- 1260 天、一載二載半載不可用來推算日期
- 「歌革和瑪各」不可指認為某個現代國家——經文自己說那是「地上四方的列國」
- 14:9–11 那段最重的審判不可用來指認任何人
- 18:20 的「歡喜」不是幸災樂禍，是公義終於來到

**原文取自公有領域校勘本。** 希臘文一律取自 Nestle 1904，不憑記憶生成。

## 部署到 GitHub Pages

這個專案不需要任何建置環境，推上去就能用。

**一、建立倉庫並推送**

```bash
git init
git add .
git commit -m "321聖經講義－啟示錄"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<倉庫名>.git
git push -u origin main
```

**二、開啟 Pages**

倉庫頁面 → **Settings** → **Pages** → Source 選 **Deploy from a branch** → 分支選 `main`、資料夾選 `/ (root)` → Save。

等一兩分鐘，網址會長這樣：

```
https://<你的帳號>.github.io/<倉庫名>/
```

**三、（選用）自動部署**

倉庫裡已附 `.github/workflows/pages.yml`。若想改用 GitHub Actions 部署，在 Settings → Pages 把 Source 改成 **GitHub Actions** 即可，之後每次 push 都會自動更新。

## 安裝成手機 App

網站開啟後可以裝到桌面，之後離線也能讀。

- **iPhone / iPad**：Safari 開啟 → 分享鈕 → 加入主畫面
- **Android**：Chrome 開啟 → 選單 → 安裝應用程式
- **電腦**：Chrome / Edge 網址列右側的安裝圖示

裝好之後，主畫面上會顯示：

| 版本 | 主畫面名稱 |
|---|---|
| 繁體中文 | **啟示錄講義** |
| 简体中文 | **启示录讲义** |
| English | **Revelation Study** |

App 內部的標題仍是「321啟示錄講義」，只有主畫面圖示下方的名字縮短了——手機主畫面的字數有限，太長會被截斷成「321啟示錄講…」。

第一次連線後，Service Worker 會把三個語言版本與圖示都快取起來，之後完全離線可用。

### 換圖示或改名稱

名稱在 `src/book.json`，每個語言各有兩個欄位：

```json
"app":   "321啟示錄講義",   // App 內部標題、瀏覽器分頁
"short": "啟示錄講義"       // 主畫面圖示下方的名字
```

圖示有三個尺寸：180 與 192 內嵌在 `src/app/{tc,sc,en}/shell.html` 裡（base64），512 是根目錄的 `icon-512.png`。

改完都要重新 `python3 build.py`。

> 換圖時請注意：**四角要滿版，不要留白邊。** iOS 與 Android 會自己套一次圓角遮罩，原圖若已經有圓角，白色的角會露出來變成白邊。

## 修改內容

內容都在 `src/data/` 裡，改完重新組建即可。

```bash
python3 build.py --check    # 資料健檢：節數、逐節覆蓋、六層缺漏
python3 build.py            # 組建出 index.html / sc.html / en.html / sw.js
```

只需要 Python 3，沒有其他相依套件。

### 專案結構

```
build.py                    組建腳本
index.html  sc.html  en.html    ← 組建產物，直接部署
sw.js                            ← 組建產物，離線快取
icon-512.png                     ← App 圖示（512×512）

src/
  book.json                 書卷資訊（三語書名、章數、主題色）
  sw.js.tpl                 Service Worker 模板
  app/{tc,sc,en}/
    shell.html              頁面外殼（含樣式、圖示、佔位符）
    app.js                  程式邏輯
  data/{tc,sc,en}/
    data.json               講義內容
```

`index.html` 等產物是組建出來的，**不要直接編輯**——下次組建會被覆蓋。要改請改 `src/`。

### data.json 的格式

```
ch       章數
txt      { 章: [每節經文, ...] }
blk      { 章: [ {a:起節, z:迄節, grk, lit, key, gram, exp}, ... ] }
serm     { 章: {blocks: [...]} }      講章
issues   容易誤解的經文
terrain  背景資料
tracks   主題脈絡
```

## 關於 321

國度321空中團契的核心理念：

**三個基礎**　耶穌是我的榜樣／聖經是我的準則／聖靈是我的引導
**兩個核心**　讓耶穌作王／讓耶穌得著一切的榮耀
**一個目的**　建立屬神的體系

321 服在聖經權威之下。解經的次序始終是：原文 → 文法 → 上下文 → 作者原意 → 聖經神學 → 基督與福音 → 生命應用，不倒過來。若某項理念與該章沒有直接關係，就不勉強加入。
